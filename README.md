# Colonization

Небольшой 3D-проект на Unity, посвящённый строительству и управлению объектами на игровой карте.

## Геймплей

[Видео с игровым процессом](https://github.com/user-attachments/assets/9ef00171-2a07-4122-a35d-47258f9b2149)

## О проекте

**Colonization** — проект на Unity, в котором игрок может свободно перемещаться по игровой карте, управлять камерой и размещать различные постройки,
реализованы боты сборщики которые собирают и таскают кристалы на свою базу, а уже на эти ресурсы можно построить еще новые базы

## Управление

| Клавиша     | Действие                          |
| ----------- | --------------------------------- |
| **W A S D** | Перемещение камеры                |
| **Q / E**   | Поворот камеры                    |
| **R / F**   | Изменение высоты камеры           |
| **Мышь**    | Выбор места и размещение построек |
